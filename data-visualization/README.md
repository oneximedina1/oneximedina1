# Data Visualization Projects

Charts and dashboards built with Matplotlib, Seaborn, and Plotly.

## Projects

- **sales_dashboard.py** — Monthly sales bar chart and trend line using Matplotlib
- **correlation_heatmap.py** — Feature correlation heatmap using Seaborn
- **interactive_chart.py** — Interactive revenue chart using Plotly

## Requirements

```
matplotlib
seaborn
plotly
pandas
numpy
```

Install with:
```bash
pip install matplotlib seaborn plotly pandas numpy
```
