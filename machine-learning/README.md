# Machine Learning Projects

ML models built with scikit-learn covering classification, regression, and clustering.

## Projects

- **classification_iris.py** — Iris flower classification using Random Forest
- **regression_housing.py** — House price prediction using Linear Regression
- **clustering_customers.py** — Customer segmentation using K-Means

## Requirements

```
scikit-learn
pandas
numpy
matplotlib
```

Install with:
```bash
pip install scikit-learn pandas numpy matplotlib
```
